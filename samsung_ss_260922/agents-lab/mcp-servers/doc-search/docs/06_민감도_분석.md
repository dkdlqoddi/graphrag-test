# 민감도 분석

> 교육용 참고 자료.

## 1. 무엇을 알아내는가

여러 입력이 함께 흔들릴 때, **결과를 가장 많이 좌우하는 입력이 무엇인지** 찾는 것이다.
순위가 나오면 어디를 관리해야 하는지가 정해진다.

## 2. 몬테카를로 결과로 구하는 방법

시뮬레이션을 돌릴 때 **각 시행에서 뽑은 입력값을 함께 기록해 둔다.**
그러면 시행이 끝난 뒤 입력과 결과의 관계를 그대로 볼 수 있다.

### 상관계수

각 입력과 결과 사이의 상관계수를 구하고, **절댓값이 큰 순서로 줄을 세운다.**

- 부호는 방향을 말한다. 양수면 입력이 커질 때 결과가 커지고, 음수면 반대다.
- 절댓값은 영향의 크기를 말한다. 순위는 절댓값으로 매긴다.

값의 단위가 서로 달라도 비교할 수 있다는 것이 이 방법의 장점이다.
비율과 금액을 같은 자리에 놓고 견줄 수 있다.

### 토네이도 도표

같은 순위를 가로 막대로 그려 위에서부터 긴 순으로 쌓은 그림이다.
막대가 위쪽으로 갈수록 길어져 회오리 모양이 된다.

## 3. 한 번에 하나씩 바꿔 보는 방법

다른 입력을 기준값에 고정하고 **한 입력만 최소에서 최대까지 움직여** 결과가
얼마나 변하는지 본다. 이해하기 쉽지만 입력끼리 얽혀 있을 때는 놓치는 것이 생긴다.

## 4. 순위가 안정적인지 확인한다

민감도 순위는 시행 횟수가 적으면 흔들린다.
**난수 시드를 바꿔 여러 번 돌려 같은 순위가 나오는지 확인한다.**
순위가 바뀌면 시행 횟수를 늘린다.

## 5. 주의

- 상관계수는 **직선 관계**를 본다. 관계가 크게 휘어 있으면 과소평가될 수 있다.
- 범위가 좁게 주어진 입력은 영향이 작아 보인다. **실제로 덜 중요한 것이 아니라
  덜 흔들리도록 주어진 것**일 수 있다. 순위를 읽을 때 입력의 범위를 함께 본다.
