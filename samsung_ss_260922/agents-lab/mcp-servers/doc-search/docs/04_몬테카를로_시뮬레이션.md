# 몬테카를로 시뮬레이션

> 교육용 참고 자료.

## 1. 무엇을 하는 방법인가

앞으로 어떻게 될지 모르는 값이 여럿 섞여 있을 때, 그 값들을 **확률분포에서 무작위로 뽑아
한 번의 시나리오를 만들고, 그 시나리오를 아주 여러 번 반복**해 결과의 분포를 얻는 방법이다.

한 번의 계산으로 하나의 예상값을 내는 것과 다르다. 결과가 하나의 숫자가 아니라
**분포**로 나오므로, 잘 될 때와 안 될 때가 어느 정도인지 함께 볼 수 있다.

## 2. 절차

1. 어떤 값을 확률변수로 둘지 정한다. 확정된 값은 확률변수로 두지 않는다.
2. 각 확률변수에 맞는 분포를 고른다.
3. 한 번의 시행에서 각 확률변수를 한 번씩 뽑는다. 이것이 하나의 시나리오다.
4. 그 시나리오로 모형을 끝까지 계산한다.
5. 3~4를 N회 반복하고, 나온 결과들을 모아 분포로 정리한다.

시간에 따라 값이 달라지는 모형에서는, 한 시나리오 안에서 값을 **한 번만 뽑아 끝까지 쓸지**
**매 기간마다 다시 뽑을지**를 정해야 한다. 사업 전망처럼 "이런 환경이 이어진다면"을 보는
경우에는 보통 시나리오마다 한 번 뽑는다.

## 3. 시행 횟수와 수렴

시행 횟수 N 이 커질수록 결과가 안정된다. 오차는 대체로 **1/√N 에 비례해** 줄어든다.
N 을 100배 늘려야 오차가 10분의 1이 된다.

수렴을 확인하는 방법은 다음과 같다.

- **N 을 늘려 가며 같은 지표를 다시 계산한다.** 값이 더 이상 의미 있게 변하지 않으면
  그 지점을 쓴다.
- **난수 시드를 바꿔 여러 번 돌린다.** 시드마다 결과가 크게 흔들리면 N 이 부족한 것이다.

수천~수만 회면 평균과 중앙값은 대체로 안정된다. 다만 **꼬리 쪽 지표**(하위 5%, 특정
사건의 확률)는 표본이 적어 더 큰 N 이 필요하다.

## 4. 결과를 무엇으로 요약하는가

| 지표 | 무엇을 말해 주는가 |
|---|---|
| 평균 | 전체를 하나로 줄인 값. 꼬리에 끌려간다 |
| 중앙값 | 절반이 이보다 낫고 절반이 이보다 못한 값 |
| 하위 5% | 나쁜 쪽으로 흘렀을 때 어느 정도인지 |
| 상위 5% | 좋은 쪽으로 흘렀을 때 어느 정도인지 |
| 특정 사건의 확률 | 예를 들어 결과가 0 미만이 될 비율 |

평균만 보고하면 분포를 본 의미가 사라진다. **중앙값과 꼬리를 함께 보고한다.**
