# 레시피 변경 승인 절차

> 이 문서는 **가상의 문서**입니다. 실제 규정이 아닙니다.

## 1. 변경 등급

레시피 변경은 영향 범위에 따라 세 등급으로 나눈다.

- **경미 변경** — 계측 항목 추가처럼 공정 조건을 건드리지 않는 변경.
  파트장 승인으로 끝난다.
- **일반 변경** — 온도·압력·시간 중 하나를 기준값의 5% 이내에서 조정하는 변경.
  공정기술팀 검토와 파트장 승인이 함께 필요하다.
- **중대 변경** — 기준값의 5%를 넘거나, 사용 가스 종류가 바뀌는 변경.
  공정기술팀·품질팀·설비팀 세 곳의 합의가 필요하다.

## 2. 절차

1. 변경 요청서를 작성한다. 변경 전후 값과 근거 데이터를 함께 넣는다.
2. 등급을 판정한다. 판정은 공정기술팀이 한다.
3. 등급별 승인을 받는다.
4. **검증 로트 3매**를 투입해 계측 결과를 확인한다.
5. 결과가 관리 한계 안이면 정식 반영하고, 벗어나면 요청서를 되돌린다.

중대 변경은 검증 로트를 3매가 아니라 **9매**로 늘린다.

## 3. 되돌리기

정식 반영 후 30일 안에 수율 이상이 확인되면 변경 전 레시피로 되돌린다.
되돌릴 때는 승인 절차를 다시 밟지 않고, 사후에 기록만 남긴다.
되돌린 이력이 있는 레시피는 같은 방향으로 6개월간 다시 변경하지 않는다.
