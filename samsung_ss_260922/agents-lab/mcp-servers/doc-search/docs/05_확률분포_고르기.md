# 주어진 형태에 맞는 확률분포 고르기

> 교육용 참고 자료.

자료가 어떤 **형태**로 주어졌는지를 보면 어떤 분포를 쓸지 정할 수 있다.

## 1. 최소 · 기준 · 최대 세 값이 주어졌을 때 — 삼각분포

전문가가 "잘해야 이만큼, 보통 이 정도, 나빠도 이만큼"으로 답한 값이 이 형태로 남는다.
**삼각분포(triangular distribution)** 를 쓴다.

- 최소값과 최대값 바깥은 나오지 않는다. 물리적으로 불가능한 값을 막아 준다.
- 기준값(최빈값) 근처가 가장 자주 나온다.
- 모양이 좌우로 기울 수 있다. 기준값이 가운데에 있을 필요가 없다.

파이썬 표준 라이브러리로는 `random.triangular(low, high, mode)` 를 쓴다.
**인자 순서가 최소·최대·최빈값이다.** 최빈값이 세 번째라는 점을 자주 틀린다.

## 2. 평균과 표준편차가 주어졌을 때 — 정규분포

과거 실적을 모아 평균과 흩어진 정도를 낸 값이 이 형태로 남는다.
**정규분포(normal distribution)** 를 쓴다.

- 평균 근처가 가장 자주 나오고 양쪽으로 대칭이다.
- 이론상 값의 범위에 끝이 없다. **비율처럼 음수가 될 수 없는 값**에 쓸 때는
  0 미만이 나오지 않도록 잘라 주어야 한다.

파이썬 표준 라이브러리로는 `random.gauss(mu, sigma)` 를 쓴다.

## 3. 값이 하나만 주어졌을 때 — 확률변수로 두지 않는다

계약으로 정해졌거나 이미 확정된 값이다. 흔들릴 이유가 없으므로 상수로 둔다.
확정된 값까지 확률변수로 만들면 결과의 흩어짐이 실제보다 커진다.

## 4. 정리

| 주어진 형태 | 고르는 분포 | 파이썬 |
|---|---|---|
| 최소 · 기준 · 최대 | 삼각분포 | `random.triangular(min, max, mode)` |
| 평균 · 표준편차 | 정규분포 | `random.gauss(mean, std)` |
| 단일값 | 없음 (상수) | 그대로 사용 |

형태가 섞여 주어졌다면 **변수마다 따로 판단한다.** 전부 같은 분포로 묶지 않는다.
