# 계측 장비 교정 기준

> 이 문서는 **가상의 문서**입니다. 실제 규정이 아닙니다.

## 1. 교정 주기

- **막 두께 측정기** — 3개월. 표준 시편 5매로 확인한다.
- **선폭 측정기(CD-SEM)** — 1개월. 배율 교정을 함께 수행한다.
- **파티클 계수기** — 2주. 주기가 가장 짧다.
- **저항 측정기** — 6개월.

교정을 마친 장비는 교정 일자와 다음 예정일을 장비 표면에 부착한다.

## 2. 교정 실패

표준 시편 측정값이 허용 편차를 벗어나면 교정 실패로 처리한다.
허용 편차는 막 두께 ±1.5%, 선폭 ±2.0%, 파티클 계수 ±10% 다.

교정에 실패한 장비는 즉시 사용을 중단하고, **직전 교정 이후 측정한 값 전부를
재검토 대상**으로 올린다. 재검토 결과 영향이 확인되면 해당 기간의 로트를
품질팀이 다시 판정한다.

## 3. 예외

신규 도입 장비는 반입 후 첫 3개월간 주기를 절반으로 줄여 운용한다.
이 기간에 교정 실패가 한 번도 없으면 정상 주기로 전환한다.
한 번이라도 실패하면 절반 주기를 3개월 더 이어 간다.
